A token launch radar in plain Node.js: scores 198 pre-token protocols from a DefiLlama snapshot with a defensible comparable-multiples model (category median mcap/TVL, growth, age and chain adjustments), ranks them by implied value, and renders a filterable dashboard with per-protocol breakdowns and 7-step farm plans. Covers all 40 watchlist protocols.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
